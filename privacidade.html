Robô de Remessa

Política de privacidade

Esta política descreve a versão local do Robô de Remessa, executada no Windows para uso próprio.

Dados consultados e finalidade

O robô consulta o código de autorização e a quantidade de devoluções previstas no painel do Mercado Livre, usando os perfis do Chrome escolhidos pelo usuário. Com a permissão da API do Google Planilhas, lê o arquivo indicado na configuração, identifica a aba do mês e confere a data, a conta e as células correspondentes.

Gravação e armazenamento

Os códigos e as observações de devolução são gravados no Google Planilhas, no arquivo escolhido pelo usuário. A autorização do Google, a configuração e o registro de execução ficam no computador em que o robô roda. O registro local inclui datas, nomes das contas configuradas, linhas processadas, contagens e mensagens de erro. O Chrome gerencia as sessões do Mercado Livre nos perfis selecionados.

Controle do acesso e retenção

O usuário controla a planilha de destino e pode remover a autorização do robô na página de conexões da Conta Google. A autorização e o registro ficam no computador até serem apagados pelo usuário. As informações gravadas na planilha ficam sob o controle de quem gerencia o arquivo.

Uso de dados do Google

O robô usa os dados recebidos pela API para localizar as linhas e realizar o preenchimento solicitado. Esse uso segue os requisitos de Uso Limitado da Política de Dados do Usuário dos Serviços de API do Google.

Contato

Para assuntos relacionados a esta política, use o e-mail de suporte informado na tela de autorização do app.
